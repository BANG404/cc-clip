## What's New in v0.12.2

A small release: two `connect` fixes contributed by @paigeman, and Grok Build paste support documented.

### Grok Build pastes through the Codex target

Grok Build (xAI's `grok` CLI) reads the clipboard in-process over X11, the same way Codex does, so it works with the existing Codex path. No new flag is needed:

```bash
cc-clip connect <host> --codex    # or --all to keep Claude Code as well
```

Open a new SSH session afterwards so the shell picks up the display setting. This is verified against Grok Build's source, not yet end to end on a real host (#147). Grok Build gives up on a clipboard read after about 2 seconds, so a large image over a slow link may not arrive in time.

### Remote binaries built locally report their version

When `connect` cannot download a matching release binary and cross-compiles one on your machine instead (typically a build from source), that binary now carries your local cc-clip version, as release builds do. Before, `cc-clip --version` on such a remote printed `cc-clip dev`. (#163, @paigeman)

### `connect --no-notify` no longer claims notifications were configured

An Antigravity-only `cc-clip connect <host> --agy --no-notify` skipped notification setup but still printed "Antigravity notifications configured". It now says they were skipped. (#164, @paigeman)

## Upgrade

**Local machine first, then each remote host.**

```bash
# macOS / Linux, existing install
cc-clip update

# macOS / Linux, fresh install
curl -fsSL https://raw.githubusercontent.com/ShunmeiCho/cc-clip/main/scripts/install.sh | bash
```

```powershell
# Windows, install or upgrade
irm https://raw.githubusercontent.com/ShunmeiCho/cc-clip/main/scripts/install.ps1 | iex
```

Then, for every remote host:

```bash
cc-clip connect <host> --force
```

## Not in This Release

- **Grok Build notifications** would need a `--grok` target wired to `~/.grok/config.toml`; that waits for a confirmed real-host paste (#147).
- **Persistent per-host SSH tunnels** (#108, Phase 1a in #165) are in review with the contributor.
- **Kimi Code, MastraCode and Grok Build paste** are not verified end to end with the real CLIs, and the Windows, opencode, Antigravity and Cursor notification paths are not verified on real hardware by us; `cc-clip doctor --host` shows when each last delivered a notification on your machine. Reports welcome.
